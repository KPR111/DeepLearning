Each Swin Block consists of Normal 2 Transformer Blocks ,where first Transformer Block Attnetion is replaced with Window Multi Head Self Attention
and Second Transformer Block Attention is replaced with Shifted Window MHSA/MSA


Hierarchical Learning in the Swin Transformer means that the model processes images at multiple different scales (resolutions) as it gets deeper.

Let's go through this Window Terminology

group(pixels)  -> patch
group(patches) -> window
group(windows) -> Image

so pixels -> patches -> windows -> image

So let's continue from ViT i.e let's continue from patches 
[In Vit every Image is size of 16x16 patches]

Let's calculate the TC of ViT 
Let N be the number of patches
See in attention weigths we have QKt product i.e there are N queries and N keys , then QxKt is N*N i.e N**2 TC 
i.e ViT ~ O(N**2)
let p be the patch size then number of patches = H/p * W/p => (HW)/P**2
i.e ViT ~ O((HW)/P**2)**2 
i.e on doubling the resolution of the image , our complexity increases by 4 times


Let's calculate the TC of Swin Transformer
See Here we don't calcualte the Attention for the Entire Image Directly instead take windows for each window calcualte the Attention in only that window only
